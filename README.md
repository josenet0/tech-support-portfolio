Tech Support & Monitoring Portal 🛠️
This project is a functional Technical Support Center designed to bridge the gap between IT Infrastructure and Software Development. It features a custom-built environment focused on User Experience (UX), system monitoring, and streamlined support workflows.

🚀 Key Features
Dynamic System Status Banner: A real-time status indicator implemented via custom PHP snippets and CSS, allowing for immediate communication of infrastructure health.

Modular Support Interface: A responsive 3-column grid system designed for high-priority resources:

Knowledge Base: Technical documentation for self-service.

Ticket System: Direct intake for complex technical challenges.

Live Chat: Real-time assistance for urgent system maintenance.

Automated Navigation: Configured WordPress CMS hierarchy to ensure the support portal acts as the primary landing page.

Contact & Location Integration: Built-in contact section with API-driven map integration for local support presence.

📂 Project Structure
This repository contains the public folder from a Local WP environment.

Note: To keep the repository clean and focused on development, I have excluded the WordPress core files, focusing only on the application layer, custom styles, and logic within the wp-content and site root.

🛠️ Technologies Used
CMS: WordPress.

Frontend: Elementor (Modular Grid System).

Backend/Scripting: PHP (Custom Snippets for Status Banner).

Styling: Custom CSS for UI/UX enhancements.

Environment: Local WP for development and testing.

📈 Developmental Goals
This project serves as a practical application of:

Clean Code Principles: Managing custom scripts within a CMS environment.

Quality Assurance (QA): Testing responsive layouts and navigation flows to ensure 100% operational uptime.

Infrastructure Awareness: Creating tools that directly solve real-world support and monitoring problems.
